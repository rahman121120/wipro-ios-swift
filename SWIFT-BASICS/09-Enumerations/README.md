
# Enumerations in Swift

## Objective
Understand how to define and use enumerations to represent fixed groups of related values.

## Concepts Covered
1. Basic Enumerations
2. Switch with Enums
3. String Raw Values
4. Integer Raw Values
5. Associated Values
6. Methods in Enums
7. Computed Properties
8. CaseIterable
9. Failable Raw Value Initialization

## Important Notes
- Enums define a finite set of related cases.
- Raw values are predefined values associated with cases.
- Associated values store additional information.
- Enums support methods and computed properties.
- CaseIterable provides access to all cases.
- Raw value initialization returns an Optional.

## Learning Outcome
Learned how to model fixed choices and application
states using Swift enumerations.
