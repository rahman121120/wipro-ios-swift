# Functions in Swift

## Objective
Understand how to define, call and reuse functions in Swift.

## Concepts Covered
1. Basic Functions
2. Functions with Parameters
3. Return Values
4. Multiple Parameters
5. Default Parameters
6. Argument Labels
7. Omitting Argument Labels
8. Tuple Return Values
9. Inout Parameters
10. Function Overloading

## Learning Outcome
Learned how to create reusable functions and
manage inputs, outputs and parameter behavior in Swift.
