# Collections in Swift

## Objective
Understand how Swift stores and manages groups of values.

## Concepts Covered

1. Arrays
2. Sets
3. Dictionaries
4. Tuples
5. Collection Iteration
6. map()
7. filter()
8. reduce()

### Arrays
- append()
- insert()
- remove()
- count

### Sets
- insert()
- remove()
- contains()
- union()
- intersection()

### Dictionaries
- Access values using keys
- Add and update key-value pairs
- removeValue()

### Higher-Order Functions
- map() transforms elements.
- filter() selects elements.
- reduce() combines elements.

## Learning Outcome

Learned how to store, access, modify and
process collections of data using Swift.
