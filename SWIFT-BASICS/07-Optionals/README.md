
## Objective
Understand how Swift handles missing or unavailable values safely.

- An Optional can contain a value or nil.
- if let safely unwraps an Optional.
- guard let supports early exit.
- Force unwrapping can cause runtime crashes.
- Nil coalescing provides a default value.
- Optional chaining safely accesses nested values.
- Implicitly unwrapped Optionals should be used carefully.

## Learning Outcome

Learned how to handle missing values safely
using Swift's Optional system.
