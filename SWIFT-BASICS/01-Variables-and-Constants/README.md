
# Variables and Constants in Swift

## Objective
Understand how to declare and use variables and constants in Swift.

## Concepts Covered
- Variable declaration using var
- Constant declaration using let
- Type inference
- Type annotations
- String interpolation
- Basic data types

## Key Differences

| var | let |
|---|---|
| Mutable variable | Constant |
| Value can be changed | Cannot be reassigned |

## Practical Implementation

Created a Swift program demonstrating:
1. Variable declaration
2. Constant declaration
3. Type inference
4. String interpolation
5. Basic data types

## Learning Outcome

Understood how Swift handles variables, constants,
and type safety.
