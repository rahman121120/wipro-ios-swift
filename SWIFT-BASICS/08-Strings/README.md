# Strings and String Manipulation in Swift

## Objective
Understand how to create, modify, compare and process strings.

## Important Notes
- Swift strings support Unicode.
- Strings are value types.
- String interpolation uses \(expression).
- String indexing uses String.Index rather than integer indexes.
- Optional binding can safely convert strings into numbers.

## Learning Outcome
Learned how to manipulate and process strings
using Swift's built-in properties and methods.
